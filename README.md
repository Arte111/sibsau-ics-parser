# Расписание СибГУ → .ics

Скрипт скачивает расписание с `timetable.pallada.sibsau.ru` для нескольких групп,
раскладывает двухнедельный цикл по датам семестра и кладёт готовые `.ics` в каталог
`timetable/` этого же репозитория. GitHub Actions запускает его каждые 6 часов и коммитит
результат, если расписание изменилось. Google Calendar подписан на файлы по ссылке.

## Файлы

```
sibsau_timetable.py               скрипт (зависимости описаны внутри, PEP 723)
config.toml                       группы, даты семестра, адрес репозитория
.github/workflows/timetable.yml   запуск раз в 6 часов
timetable/*.ics                   результат, создаётся автоматически
test_parser.py                    офлайн-проверка парсера (не нужна для работы)
```

## Запуск в GitHub

1. Скопируйте `sibsau_timetable.py`, `config.toml`, `.gitignore` и папку `.github`
   в корень публичного репозитория, с которого работает GitHub Pages
   (например `arte111.github.io`).
2. В `config.toml` укажите свои группы и `base_url` — адрес репозитория на Pages.
3. Закоммитьте и запушьте:
   ```bash
   git add -A && git commit -m "Расписание СибГУ" && git push
   ```
4. Откройте вкладку **Actions** в репозитории. Если Actions выключены, GitHub предложит
   их включить кнопкой «I understand my workflows, go ahead and enable them».
5. Выберите workflow «Обновление расписания» → **Run workflow** → ветка `main` → Run.
   Прогон занимает меньше минуты.
6. В логе прогона найдите строки «Ссылка для подписки» — это адреса ваших `.ics`.
7. Проверьте, что ссылка открывается в браузере. Если 404 — включите Pages:
   Settings → Pages → Source: Deploy from a branch, ветка `main`, папка `/ (root)`.
   Первая сборка занимает до 10 минут.
8. В Google Calendar: слева «Другие календари» → «+» → **Подключить по URL**, вставьте
   ссылку. Повторите для каждой группы. Это делается один раз.

Дальше всё работает само: cron в workflow запускает скрипт каждые 6 часов.

Секреты настраивать не нужно — `permissions: contents: write` даёт workflow право
коммитить через встроенный `GITHUB_TOKEN`.

## Локальный запуск

```bash
uv run --script sibsau_timetable.py --dry-run   # показать, что изменилось бы
uv run --script sibsau_timetable.py --no-git    # записать .ics без коммита
uv run --script sibsau_timetable.py             # как в CI: записать и закоммитить
```

## Что нужно знать

- Google обновляет календари, подключённые по URL, раз в 8–24 часа. Скрипт публикует
  изменения сразу, но в вашем календаре они появятся с задержкой, и ускорить это нельзя.
- Коммит создаётся, только если расписание реально изменилось: при сравнении игнорируются
  поля `DTSTAMP`, `PRODID` и `LAST-MODIFIED`, которые меняются при каждой генерации.
- Cron в GitHub задаётся в UTC, запуск может задержаться на десятки минут при нагрузке.
- Если в публичном репозитории 60 дней нет активности, GitHub отключает запуск по
  расписанию. Он присылает письмо, включается обратно одной кнопкой в Actions.
- Номер текущей недели берётся с активной вкладки сайта, а если разметка изменилась —
  по правилу СибГУ: нечётная ISO-неделя → 1-я неделя. Если недели встали наоборот,
  поставьте в `config.toml` `week_offset = 1`.
- «Занятий не найдено» — проверьте id группы, открыв URL в браузере.
